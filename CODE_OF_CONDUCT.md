# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and constructive, assume good intent, and keep discussions about the
work. Harassment, insults and personal attacks aren't tolerated in issues, pull requests
or any other project space.

The maintainer may edit or remove comments, and block people who break these rules. To
report a problem privately, use GitHub's
[report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature, or ask in an issue for a private way to get in touch, without giving details there.
