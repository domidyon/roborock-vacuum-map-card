# Security

The card runs in your Home Assistant dashboard and talks only to your own Home Assistant
instance. It stores no credentials. *Copy diagnostics* redacts tokens and signed URLs
before anything reaches your clipboard.

## Reporting a vulnerability

Please don't open a public issue for security problems. Use GitHub's private
**[Report a vulnerability](https://github.com/domidyon/roborock-vacuum-map-card/security/advisories/new)**
form. If it isn't available, open an issue that only asks for a private contact, without
any details.

This is a hobby project: there's no bug bounty and no guaranteed response time, but
reports are taken seriously and fixed as soon as possible.

## Supported versions

Only the latest release and the `beta` branch receive fixes.
